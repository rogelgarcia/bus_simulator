# config

Tracked versioned defaults: source_poses preserves user payloads; poses binds five cameras to four buses; baseline preserves the existing game configuration; lighting names six relative illumination trials; render_profiles declares sample/bounce/denoising budgets; color_management declares views/exposure/grades; analysis declares thresholds/crops/shortlisting. These files never contain local hardware paths. Every run snapshots effective inputs.

See the [workflow README](../README.md) for commands, configuration, provenance and limitations.
